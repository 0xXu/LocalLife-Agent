# WeekendPilot 演示脚本

主体验通过 Next.js API + LangGraph workflow + MCP-ready tools 运行。Python backend 是迁移前的参考实现，不是主演示路径。

## 第一幕：一句话到完整计划

1. 运行 `npm run dev`，打开 `http://127.0.0.1:4173`。
2. 在首页输入框粘贴：`今天下午是空的，想和老婆孩子出去玩几个小时，别离家太远。孩子 5 岁，老婆最近在减脂，帮我安排一下。`
3. 点击 **生成计划**。
4. 预期屏幕文案：**已理解你的需求**、**Agent 执行轨迹**、**主方案**、**地图与路线**。
5. 展示重点：约束卡片、可展开工具轨迹、半日时间轴、路线摘要、六个待确认动作。

## 第二幕：计划到执行回执

1. 在规划页点击底部 **确认执行**。
2. 预期屏幕文案：**执行回执**。
3. 预期回执编号：`TKT-`、`RES-`、`CPN-`、`ORD-`、`MSG-`、`CAL-`。
4. 展示重点：预约活动、预订餐厅、领取团购券、创建点单、发送计划和写入日历都只在用户确认后执行。

## 第三幕：餐厅无位、雨天、活动满员任选一个失败恢复

1. 默认选择餐厅无位恢复，在规划页点击 **模拟餐厅无位**。
2. 预期屏幕文案：**原方案**、**新方案**、**预算变化**、**路线变化**、**重新确认执行**。
3. 展示重点：系统保留活动和饭后安排，只替换不可订餐厅，并展示预算、路线和保留节点差异。
4. 备选讲法：恢复策略矩阵还覆盖活动满员、雨天、路线超时、预算超限、约束冲突和工具超时。
