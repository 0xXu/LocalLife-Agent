# WeekendPilot 演示脚本

主体验通过前后端分离架构运行：

```text
Next.js 前端 -> FastAPI 后端 -> Python PlanningService -> PlanningPipeline -> backend/tools
```

## 第一幕：一句话到完整计划

1. 启动后端：`npm run dev:backend`。
2. 启动前端：`npm run dev`。
3. 打开 `http://127.0.0.1:4174`。
4. 在首页输入：“今天下午朋友 4 个人出去玩，先活动再吃饭，路线别绕远，预算 500 元以内。”
5. 点击 **生成计划**。
6. 预期：页面立即进入生成中状态，随后展示约束卡片、Agent 执行轨迹、候选筛选、主方案、路线和待确认动作。

## 第二幕：计划到执行回执

1. 在规划页点击 **确认执行**。
2. 预期：展示活动预约、餐厅订座、团购券、点单、消息和日历等模拟执行回执。
3. 展示重点：所有副作用动作都先经过确认快照，再返回可核验回执。

## 第三幕：失败恢复

1. 在规划页点击 **模拟餐厅无位**。
2. 预期：页面展示原方案、新方案、预算变化、路线变化和重新确认入口。
3. 展示重点：恢复流程只替换冲突节点，保留其他行程安排。

## 可补充展示

- FastAPI OpenAPI 文档：`http://127.0.0.1:8787/docs`
- LLM 状态：`http://127.0.0.1:8787/api/llm/status`
- 最近执行、保存计划、偏好设置和移动端布局交互。
